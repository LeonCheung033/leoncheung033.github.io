# leoncheung033.github.io

Leon Cheung 个人网站的本地草稿，基于
[al-folio](https://github.com/alshedivat/al-folio) 构建。

网站目前保持简洁，仅包含：

- 关于
- 博客
- 项目

本地启动与验证：

```bash
bundle install
npm ci
bundle exec jekyll serve
```

网站地址为 `https://leoncheung033.github.io`，通过 GitHub Pages 发布。
后续任何推送或公开内容变更，都需要 Leon 在执行时明确授权。详见
[docs/SITE.md](docs/SITE.md)。
