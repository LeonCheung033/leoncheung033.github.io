# Decision notes

This personal site keeps small decision notes for changes that affect visible
site behavior, public content, deployment, or handling of personal assets.

- `proposed/<class>/YYYY-MM-DD-topic.md`: accepted direction not yet verified.
- `implemented/<class>/YYYY-MM-DD-topic.md`: locally shipped and verified.
- `rejected/<class>/YYYY-MM-DD-topic.md`: evaluated but declined.

Classes are `feature`, `bug-fix`, `simplification`, `architecture`, `process`,
and `testing`. The lifecycle path must match the `Status:` line. Publishing to
GitHub remains separate from local implementation and always requires the site
owner's explicit authorization.
